# README media

- `hero.svg`: native `.esp → .bin` banner showing our compiler, assembler/linker and firmware builder, generated by `npm run docs:assets`.
- `architecture.svg`: shared frontend, native and Arduino build paths, upload boundaries, and hosted worker overview; generated by the same command.
- `native-pipeline.gif`: illustrated native pipeline, generated by `npm run docs:assets` with Sharp and gifenc. This is not a hardware recording or a native IDE preview.
- `native-pipeline-metadata.json`: dimensions, frame count, duration and provenance of that illustration.
- `studio-demo.gif`: actual isolated browser interactions, captured by `npm run docs:record`.
- `ide-overview.png` and `ide-mobile.png`: safe static screenshots from that recording.
- `demo-metadata.json`: dimensions, duration, frame count, and capture description.
- `hosted-studio.png`: successful real Linux container build, captured by `scripts/test-hosted.mjs` in GitHub Actions; this snapshot is separate from the local README tour.

Run the application before recording. Set `README_DEMO_URL` to select its origin and `CHROME_PATH` to use a specific browser executable. The recorder uses a fresh context and bundled examples, and never requests a USB port. It does not alter the running user's editor or browser storage.

The SVGs are designed for GitHub Markdown image rendering and contain no scripts, external fonts, or embedded HTML. They include accessible titles and descriptions. GIFs supply animation independently of SVG animation support; the static architecture is an alternative to the native animation. Visual-review PNGs go to ignored `.verification/readme-assets/`.
